# Геометрические фигуры (C++)

## Описание проекта
Данный проект был выполнен в рамках лабораторной работы по дисциплине 
«Системы контроля версий Git и GitHub».

Цель проекта — реализовать функции для вычисления параметров 
геометрических фигур с использованием языка программирования C++ 
и системы контроля версий Git.

Проект разрабатывался группой из нескольких студентов. 
Каждый участник реализовывал свою фигуру в отдельной ветке репозитория.

---

## Реализованные фигуры

### Прямоугольник
Файл: rect.cpp

Функции:
- вычисление периметра
- вычисление площади
- вычисление диагонали

---

### Треугольник
Файл: triangle.cpp

Функции:
- вычисление периметра
- вычисление площади по формуле Герона
- проверка на равнобедренность

---

### Трапеция
Файл: trapezoid.cpp

Функции:
- вычисление периметра
- вычисление площади
- вычисление средней линии

---
